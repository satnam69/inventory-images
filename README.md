# inventory-images

Item images for the server's ox_inventory, served by GitHub Pages:

    https://hightechrp.github.io/inventory-images/images/<item>.png

ox_inventory reads this via `setr inventory:imagepath` in `ox.cfg`.
To add or change an image: drop the PNG (named after the item) into `images/`, commit, push.
Pages updates within a minute or two; players may need to clear the NUI cache to see a changed image.
